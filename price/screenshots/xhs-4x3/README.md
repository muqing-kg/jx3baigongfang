## 演示数据说明

- 服务器：**梦江南**；`80% 已校准`（210 / 263），53 项示例价，0 项缺价。
- 价格来自项目内置的 JX3BOX 17 服拍卖样本 / 示例价，**不是实时交易行**。
- 所有数字仅用于展示界面，不构成收益承诺。
- `03`、`04`、`10` 为便于手机阅读，分别按 1.35×、1.25×、1.12× 界面缩放拍摄。
- `06` 隐藏了同页的价格表，便于把「跨服比价」放在一屏内；其余为实机页面。
- `11` 由手机端（390 × 844）截图合成到品牌底色上，非直接网页截图。

## 重拍

本地启动静态站点后，用 Playwright（Chromium）以 `1600 × 1200` 视口逐页截图即可：

```bash
python3 -m http.server 8931
# 打开 http://127.0.0.1:8931
```

截图状态建议与本次保持一致，避免不同图片里的服务器、校准比例、预算数字互相矛盾。
