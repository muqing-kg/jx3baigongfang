04 · HOW TO

最常用的 4 个操作

改配方、批量改价、换口径、满精力模拟——这四个会了，基本就够用。

01 / 配方

改配方 / 新增配方

  • 生活技艺 → 点配方行 → 详情抽屉 → 编辑配方
  • 或右上角「新增配方 / 新增采集点」
  • 可改等级、精力、手续费、产物、材料
内置配方可「恢复示例」；自定义配方可删除。
适合：版本更新后改配方，或自建一套采集路线。
02 / 价格

批量改价

  • 价格库 → 批量录入
  • 从游戏内交易行复制「物品名 价格」，支持逗号/制表符/空格
  • 只匹配已有物品，未匹配会单独提示
失焦或回车即保存；支持导出 CSV，完整备份用 JSON 导入 / 导出。
适合：版本初期，先把常用材料补齐。
03 / 口径

换成本口径

  • 生活技艺 / 分析页右上角：市场价 / 取最低
  • 取最低：材料取 min(市场价, 自制成本 ÷ 产出数量)
  • 它只优化材料成本，不把中间产物的精力计入最终配方
想比全链路精力效率，用市场价或合并成一条自定义配方。
适合：有大量中间产物、想压材料成本时。
04 / 模拟

满精力怎么分

  • 分析页 → 满精力怎么分配
  • 输入预算（默认 3000），按效率从高到低贪心分配
  • 可重复制作，显示预计总金币 / 精力用尽 / 剩余
不建模交易税、暴击额外产出、市场深度；可用手续费手动修正。
适合：精力快满，想知道先做哪个。

05 · READING

别只看单次金币：3 个读数习惯

同一个配方，换个口径就是另一个结论。先把下面这几个数看对。

计算口径

材料成本Σ（数量 × 单价）
总成本材料成本 + 手续费
产值Σ（产物数量 × 单价）
单次金币产值 − 总成本
精力效率单次金币 ÷ 精力
毛利率单次金币 ÷ 产值
价格默认取本服市场价；交易税、暴击、署名溢价未自动计入。
1

先看「精力效率」

同样 3000 精力，做不同配方差距可能很大。精力效率 = 单次金币 ÷ 精力，才是「每一份精力换多少金」。

2

再看「成本 + 毛利率」

单次金币高，可能压资金；毛利率高，可能周转快。两个一起看，才知道适不适合自己。

3

看数据状态

缺价 / 数据不全时，效率会被低估；先补价再下结论。别拿示例价当本服实时价。

看榜前自检 服务器对吗？缺价补了吗？口径选对了吗？
容易踩的坑更稳的读法
只看单次金币同时看「精力效率 + 毛利率」
用别服 / 旧价直接算先校准本服价格，再看 Top 10
把示例价当实时行情当趋势参考，关键材料自己校准
把「取最低」当全链路它只优化材料成本，精力仍按本配方算
记住这 3 句 精力效率优先 先补价，再看榜 取最低只优化材料成本

07 · TRUST

口径、边界与 FAQ

先把「数据从哪来、什么没算」说清楚，比多算两个配方更重要。

苍生铸世 · 50 级 数据 v3.3 核验 2026-11-18 154 制造 + 17 采集 263 物品 17 服物价
Q1为什么和游戏内交易行不一样？
价格来自第三方攻略站的 17 服样本 / 示例价，不是实时行情；交易税、暴击、署名溢价也未自动计入。请以游戏内交易行为准。
Q2为什么有「缺价」？
该物品没有有效价格，效率会按 0 计，配方被标为「被低估」。去价格库补价后，全站会自动重算。
Q3「取最低」为什么精力没变少？
它只优化材料成本：逐层取 min(市场价, 自制成本 ÷ 产出数量)，不会把自制中间产物消耗的精力计入最终配方的精力分母。
Q4暴击 / 交易税 / 署名怎么算？
未自动建模。可以把税写进「手续费」；把暴击额外产出写进「产物数量」或减少材料数量，来近似修正。
配方库

154 条当前版本代表配方 + 17 个采集点；不是官方逐条数据，可在界面内新增 / 修改。

价格

第三方攻略站 17 服样本；无报价 / 低样本回退示例价，可逐项校准。

未建模

交易税、暴击额外产出、署名溢价、市场深度、跨服交易限制。
