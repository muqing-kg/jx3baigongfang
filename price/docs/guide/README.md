## 8 页内容

1. **封面**：定位、核心数字、使用入口、三个使用场景
2. **进入**：扫码/点击单页版入口 → 选服务器 → 先用示例价
3. **3 步上手**：选服务器 → 校准价格 → 看结论
4. **功能地图**：总览、生活技艺、配方详情、价格库、精力分析、设置与备份
5. **4 个核心操作**：改配方、批量改价、换口径、满精力模拟
6. **读数习惯**：公式、精力效率优先、成本/毛利率、数据状态
7. **手机端与备份**：网页版、本机存储、JSON 导出导入
8. **口径与 FAQ**：数据来源、缺价、取最低、暴击/交易税

## 发小红书

小红书笔记支持 PDF 附件，也可以发图片。建议：

1. **单页版 PDF 直接作为笔记附件**（`docs/guide-single/`）；只能发图时，上传同名 PNG；
2. 8 页详细版可作为长文/存档，按顺序上传 `pages/` 的 8 张 4:3 图片；
3. PDF/图片里可以放二维码；**正文/评论不要写具体网址、域名、微信号**；
4. 访问写：「扫 PDF/图片里的二维码」或「点「打开物价助手」链接」；
5. 短笔记可用 `01-cover` + `03-quick-start` + `08-trust` 三张。
