# 小红书图文（单页 3:4）

参照已通过小红书审核的《剑网三效率工作台_小红书图文.pdf》做的单页版：

- **1 页**，页面比例 **3:4**（540 × 720 pt）
- 5 步上手 + 二维码入口
- **「打开物价助手 →」是 PDF 内可点击链接**；二维码同样指向工具地址
- **不打印具体网址**；链接和二维码都不在正文显示 URL
- 无游戏截图、无微信/PWA/站外平台字样
- 页脚保留「仅游戏内数值」「非官方」说明

## 发笔记

- 笔记支持 PDF 附件时，直接上传 PDF；PDF 里点「打开物价助手 →」或扫二维码都能跳转；
- 只能发图时，上传同名 PNG；**PNG 不可点击**，只能扫码；
- 二维码/链接已内置，**正文/评论不要再写具体网址**；
- 页脚已有「仅游戏内数值 / 非官方」说明，正文无需重复。

## 二维码

- 当前二维码/链接指向：在线版工具地址（不打印在 PDF 上）。
- PDF 内已生成 URI 链接注释；如果某个 PDF 查看器不支持链接，扫二维码即可。
- 如需换成其他入口，替换 `assets/qr-tool.png` 后重新导出即可。
