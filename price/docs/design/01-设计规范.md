# 数据看板 · UI 设计规范

> 面向"高密度、多模块、可下钻"的数据产品的通用界面基线。
> 结论来自对一套成熟赛事数据看板的走查，**已剥离行业术语**，可直接映射到运营、金融、监控、内容后台等场景。

---

## 1. 设计主张

| 维度 | 表现 | 结论 |
| --- | --- | --- |
| 视觉基调 | 近黑底 + 极窄描边分区 + 高饱和数据色 | "夜间工作台"气质，为长时间盯屏设计 |
| 信息密度 | 单屏 6–12 个数据块，长表 25 行、矩阵 23×7 | 高密度优先，靠**留白 + 字号层级**降噪，而非更多分割线 |
| 色彩职责 | 底色中性、彩色仅用于**编码** | 颜色即数据，这是最值得迁移的原则 |
| 交互语法 | 卡片即模块、图表即答案、控件紧贴数据 | "少跳转、原地改写视图" |
| 情绪 | 专业、克制、可信 | 粗体数字 + 实体品牌色 + 一致的排版节奏 |

**三条可复用主张**

1. **一屏一主题**：每张卡片只回答一个问题（谁最快？差距多少？本周是否异常？），标题即问题，数字即答案。
2. **控件贴着数据放**：筛选、切换、导出永远在该数据块右上角 12–40px 内，不做全局大工具条。
3. **颜色先满足编码，再满足品牌**：品牌色只用于 Logo、当前导航与关键强调，绝不与数据色混用。

## 2. 信息架构

### 2.1 导航分层

一套典型的高密度看板，导航天然分成四层，**与行业无关**：

```
主流程    总览 · 实时监控 · 时间表 · 结果汇总
排行榜    对象排行（人/物）· 分组排行
实体      对象名录 · 组织名录
深度分析  单对象详情 · 双对象对比 · 分布稳定性 · 明细时序
          效率指标 · 变更记录 · 配额消耗 · 成本损耗 · 多维属性
辅助区（固定底部）
          反馈（外链）· 更新日志 · 法务
```

**架构评价与规则**

- 17 个同级入口已是上限。超过 12 项时应加分组标题（10–11px 大写、muted 色），或把"深度分析"收进二级。
- 使用频次最高的 3–4 项固定在列表前 1–4 位；"实时"类入口应紧邻总览。
- 底部固定辅助区是低成本高收益模式，建议所有 B 端产品沿用。

### 2.2 页面层级

```
App Shell
├─ Sidebar（256px，固定）
└─ Main
   ├─ Header 64px：面包屑 + 语言 + 主题
   └─ Page
      ├─ Page Toolbar：页面标题 + 页级筛选（周期 / 对象 / 分组）
      ├─ Content Grid：12 列，卡片跨 3/4/6/8/12
      └─ Local Scroll Areas：长表、清单、动态流
```

## 3. 布局体系

### 3.1 骨架尺寸

| 元素 | 数值 | 说明 |
| --- | --- | --- |
| Sidebar 宽 | **256px** | 固定，可折叠为 56px 图标态 |
| Header 高 | **64px** | 粘顶，半透明底 + 12px 模糊 |
| 内容区宽 | 视口 − 256px | 1600 视口下为 1344px |
| 内容最大宽 | **1920px** | 超宽屏居中，不无限拉伸 |
| 页面内边距 | 24px（桌面）/ 16px（移动） | 卡片间距 16px |
| 卡片内边距 | 16–20px（密集卡 12px） | 与字号同步收敛 |

### 3.2 栅格

- **12 列 / 16px gap**，按语义跨列：KPI 4 列、对比图 6 列、全宽表 12 列。
- ≥1280 稳定 3 列卡片；1024–1279 降 2 列；≤768 降 1 列。
- 「左清单 + 右图表」模式（排行榜、配额页）：左 4 列固定、右 8 列自适应；<1280 时改为上下堆叠。

### 3.3 纵向节奏

- 卡片标题 → 主体 16px；区块之间 24px；页面标题区 56–72px。
- 同一行卡片**等高**；标题行数不同时用 `min-height` 对齐首行，避免参差。

## 4. 色彩系统

### 4.1 语义令牌（暗色为默认主题）

| Token | HSL | 近似 HEX | 用途 |
| --- | --- | --- | --- |
| `--background` | `222.2 84% 4.9%` | `#020817` | 页面底色 |
| `--card` / `--popover` | 同上 | `#020817` | 卡片底与页面同色，靠描边分层 |
| `--foreground` | `210 40% 98%` | `#F8FAFC` | 主文本 |
| `--muted-foreground` | `215 20.2% 65.1%` | `#94A3B8` | 次级文本、表头、轴标签 |
| `--border` / `--input` | `217.2 32.6% 17.5%` | `#1E293B` | 描边、分隔线 |
| `--sidebar-background` | `222.2 47.4% 11.2%` | `#0F172A` | 侧栏（比页面亮一阶） |
| `--accent` | `217.2 32.6% 17.5%` | `#1E293B` | hover / 选中底 |
| `--primary` | `210 40% 98%` | `#F8FAFC` | 主按钮（反相） |
| `--brand` | `2 100% 44%` | `#E10600` | 品牌色：Logo、当前项指示 |
| `--destructive` | `0 62.8% 30.6%` | `#7F1D1D` | 危险操作 |
| `--ring` | `212.7 26.8% 83.9%` | — | 焦点环 |

亮色主题由同一组 token 反相（`#F5F5F5` 底 / `#0F172A` 文本 / 白卡 / `#E2E8F0` 描边），**不改变任何数据色**。

### 4.2 数据序列色板

```
chart-1  220 70% 50%   #1D6FE0   主序列（蓝）
chart-2  160 60% 45%   #2E9E78   次序列（青绿）
chart-3   30 80% 55%   #E88A2E   第三序列（橙）
chart-4  280 65% 60%   #A75BE0   第四序列（紫）
chart-5  340 75% 55%   #E04A7A   第五序列（洋红）
```

### 4.3 语义状态色

| 语义 | 色值 | 出现场景 |
| --- | --- | --- |
| 最优 / 峰值 | `271 81% 56%` 紫 | 第一名、最优记录高亮 |
| 个人最佳 / 正向 | `142 69% 58%` 绿 | 提升、达标 |
| 中性提示 | `45 93% 47%` 黄 | 注意、待确认 |
| 危险 / 负向 | `345 88% 52%` 玫红 | 失败、超额、取消 |
| 信息 / 中性 | `217 91% 60%` 蓝 | 备注、辅助标记 |

### 4.4 实体品牌色

当需要区分固定数量的实体（如 10 个分组），用**每个实体自己的品牌色**做数据编码：

- 由后端下发 `entity_color_rgb`，前端以 `rgb(var(--entity-color) / α)` 使用。
- 只用于色块、描边、渐变、图表填充；**文字永不用品牌色**（对比度不可控）。
- 色值需做可访问性校验：相邻实体的色相差 ≥ 40°，或附加形状/图案区分。

### 4.5 三条硬规则

1. **一屏内彩色面积 ≤ 25%**，且彩色必须承载数据。
2. **品牌色与风险色必须分离**：品牌色只出现在品牌与导航；风险色使用独立色相并配图标或文案。
3. **不允许仅用颜色传达状态**：必须同时给数字、字母或图标。

## 5. 字体与字阶

- **字族**：`ui-sans-serif, system-ui, -apple-system, "Segoe UI", …`（系统字体栈，零加载成本）。
- **数字**：统一 `tabular-nums`，保证列对齐；KPI 可使用翻牌动画，但只播一次。

| 角色 | 字号 / 行高 | 字重 | 颜色 | 示例 |
| --- | --- | --- | --- | --- |
| 页面标题 H1 | 20 / 28 | 600 | foreground | `2026 年度结果汇总`（示例文案） |
| 区块标题 H2 | 20 / 28 | 600 | foreground | `分组结果` |
| 卡片标题 | 14–16 / 20–24 | 600 | foreground | `耗时排行 Top 20` |
| 微标签 / 表头 | **10–12** / 16 | 500–600 | muted，大写 + `tracking-wide` | `周期统计`、`序号` |
| 正文 | 14 / 20 | 400–500 | foreground | 表格行、说明文字 |
| 辅助说明 | 12 / 16–18 | 400 | muted | `已排除异常样本` |
| KPI 数值 | **24–28** / 32 | 700 | foreground | `1.99 s`、`$27,468,000` |
| 图内标签 | 10–11 | 400–500 | muted | 轴刻度、图例 |

**字重仅用 400 / 500 / 600 / 700 四档**，避免系统字体渲染差异。

## 6. 形状、描边与层级

| 元素 | 圆角 | 描边 | 阴影 |
| --- | --- | --- | --- |
| 卡片 / 弹层 | **8px**（`--radius: .5rem`） | 1px `--border` | 无（弹层除外） |
| 按钮 / 输入 / 下拉项 | **6px** | 1px，hover 提亮 | 无 |
| 徽标 / 标签 | 4px 或全圆角 | 无 | 无 |
| 头像 / 缩略图 | 全圆角或 8px | 无 | 无 |
| 浮层（菜单、Tooltip、灯箱） | 8px | 1px | `0 12px 48px rgba(0,0,0,.27)` |

**层级策略**：用"描边 + 底色明度"而非阴影表达层级。全站仅 3 种海拔：页面 (0)、卡片 (0，描边)、浮层 (+1，阴影)。

## 7. 组件规范

### 7.1 侧栏导航项

- 高度 36px，左内边距 8px，图标 16px + 文字 14px/500，间距 8px。
- 默认文字 `#E2E8F0`；hover 底 `--accent`；当前项：底 `--accent` + 左侧 2px 品牌色条。
- 折叠态 56px 仅图标，Tooltip 补名称（延迟 300ms）。
- 底部辅助项：图标 14px + 文字 12px，muted 色，外链带角标。

### 7.2 页头 Header

- 左：面包屑（`首页 / 当前页`），分隔符 1px 竖线，当前页不可点。
- 右：语言切换、主题切换、移动端菜单；统一 32×32 图标按钮。
- 粘顶 + 半透明底 + 12px 模糊，滚动时内容从下方穿过。
- 同一组件两套可见性规则（桌面隐藏移动菜单 / 移动端隐藏面包屑），避免重复 DOM 抖动。

### 7.3 页面工具条

```
[ 页面标题 / 一句话说明 ]        [ 周期 2026 ] [ 对象 25 ] [ 分组 11 ]
```

- 右侧为"作用域筛选器"，统一外观：32px 高、6px 圆角、文本标签 + 计数、下拉箭头。
- 只放**影响整页**的筛选；块级筛选进入卡片头部。
- 筛选状态应写入 URL，支持分享与浏览器回退。

### 7.4 数据卡

```
┌──────────────────────────────────────┐
│ 标题（16/600）          [控件] [⤓]   │  ← 40–48px 头部
│ 副标题 / 口径说明（12 muted，可选）    │
│ ──────────────────────────────────── │
│ 主体：表格 / 图表 / 列表 / 热力图      │
└──────────────────────────────────────┘
```

- 卡片底与页面同色，1px 描边，8px 圆角，无阴影。
- **右上角固定区**：图例切换、开关、导出（14px 下载图标）。最多 2 个控件，超出移入 `⋯` 菜单。
- 标题必须在卡片内，保证卡片可被独立截图与复用。

### 7.5 KPI 卡

```
┌────────────────────────────┐
│ 指标名（12 muted）      ⓘ  │
│ 1.99 s（28/700）  ↑ 4      │
│ +3.73% 较上周期（12）       │
└────────────────────────────┘
```

- 数值 + 单位同行，单位字号为数值的 45%，基线下沉对齐。
- Delta 用"图标 + 颜色 + 文案"三重编码。
- 环比句式固定（`+3.73% 较上周期`），统一口径降低理解成本。
- 数字变化使用 250ms 翻牌动画，**仅一次**。

### 7.6 数据表格

| 规则 | 规格 |
| --- | --- |
| 表头 | 12px / 500 / muted / 大写 / 字距 0.04em，底透明，底边 1px |
| 行高 | 40px（密集）/ 48px（标准） |
| 单元格 | 14px / 500；数字右对齐 + `tabular-nums` |
| 前导列 | 序号 4 字符宽 + 实体小图标 + 名称 |
| Hover | 行底 `rgba(148,163,184,.06)`，整行可点 |
| 选中 / 高亮 | 左侧 2px 强调色 + 底色 8% |
| 排序 | **建议**：表头可点，激活列显示 ▲▼，排序不改行高 |
| 固定列 | 首列 `sticky left-0` + 背景遮罩（宽表必需） |
| 空态 | 保留表头，body 居中一行"当前筛选无数据" |
| 长表 | 优先"完整列表 + 页内滚动"，不隐藏数据；提供导出 |

### 7.7 图表卡

- 高度：折线 280–340px；条形 320–420px；热力图按行数自适应。
- 轴：只保留必要刻度，Y 轴 4–6 格；网格线 1px `rgba(148,163,184,.12)`，仅水平。
- 图例：置于标题行右侧或图内右上角，不额外占高。
- 交互：hover 十字线 + Tooltip（深底、8px 圆角、12px 字、显示全部序列值）。
- 导出：每卡独立下载按钮（PNG），文件名含数据范围。
- **口径说明**：凡是"平均 / 排除某类 / 估算"的图，标题下必须有 12px 灰色说明。

### 7.8 分段控件

- 32px 高，底 `--accent` 20%，选中项反相（foreground 底 + background 字）。
- 用于互斥视图切换（如"全部 / 子集 A / 子集 B"）。
- 最多 4 项，超过改用下拉。

### 7.9 筛选下拉

- 触发器：`图标 + 标签 + 值 + 计数 + ⌄`，32px 高。
- 菜单：多选 + 搜索 + 全选 / 清除 + 已选数量；宽 240–320px。
- 必须提供 **Reset / Clear all**，选择后触发器显示计数。

### 7.10 开关与滑杆

- 开关：36×20，开 = 品牌色或数据色，关 = `#334155`，行内标签在左。
- 滑杆：轨道 4px，拇指 14px，**实时显示数值**，支持键盘 ±1。
- 用于"口径修饰"（排除异常、仅算有效样本、高亮重点），不用于导航。

### 7.11 徽标

- 12px / 500，圆角 4px 或全圆角，内边距 8×2。
- 类型：状态（进行中 / 已完成 / 已取消）、属性（新、替补、重点）、计数、扣减。
- 颜色由语义决定，不用品牌色做状态。

### 7.12 空态与加载

- 加载：骨架屏（灰块），**禁止**只显示 `Loading...` 文本。
- 空态：图标 + 一句结论 + 一个出口动作（切换周期 / 返回）。
- 错误：卡片级内联错误 + 重试按钮，不整页崩溃。
- 每个数据块独立降级，一个图表失败不影响其他卡片。

### 7.13 弹层体系

| 类型 | 场景 | 规格 |
| --- | --- | --- |
| 抽屉 / 侧板 | 条目详情、对象详情 | 右侧 480–560px，8px 圆角，40% 黑遮罩 |
| 灯箱 | 图集、大图 | 全屏 95% 黑底，底部缩略图条，←/→ 切换 |
| Tooltip | 图表、指标解释 | 最大 280px，12px 字，延迟 120ms |
| 菜单 | 周期、语言、筛选 | 键盘 ↑↓ 可导航 |

所有浮层：Esc 关闭、点遮罩关闭、焦点返回触发元素、`aria-modal` + 焦点陷阱。

## 8. 数据可视化规范

### 8.1 图表选型矩阵（按"要回答的问题"）

| 问题 | 图表 | 典型用法 |
| --- | --- | --- |
| 谁高谁低，排序 | 水平条形图（按值排序） | 按对象的平均耗时排行 |
| 趋势随时间 | 多折线 / 面积 | 累计值、指标演化 |
| 名次如何变化 | Bump Chart（排名折线） | 榜单排名演化 |
| 稳定性 / 波动 | 箱线图 + 参考线 | 分布稳定性、晋级阈值 |
| 构成占比 | 环形图（中心放总数） | 类型构成 470 条 |
| 二维分布 + 第三维 | 气泡散点 | 时间分布、相似度地图 |
| 矩阵对比 | 热力图 | 配额使用、属性矩阵 |
| 流向 / 转换 | 桑基图 | 起点 → 终点的状态流转 |
| 单次明细 | 多线 + 点图 | 逐笔、逐圈、逐秒 |
| 多次对比 | 小倍数（small multiples） | 每个对象一小图 |

**硬规则**：一卡一图；同一指标在不同页面必须使用同一图表类型。

### 8.2 编码规则

- **颜色**：优先实体品牌色；序列超过 6 条时启用 `chart-1..5` 并降透明度至 70%。
- **尺寸**：仅气泡图用尺寸编码，且必须在图例中说明。
- **位置**：条形图按数值排序（非字母序），第一名永远在最上。
- **参考线**：阈值、均值、达标线用虚线 + 12px 标签，是高频专业信息，必须保留。
- **不做** 3D、双 Y 轴、饼图（除环形占比）。

### 8.3 图注与可信度

易误读处必须加说明：

- 复杂图表下方 1 段 12px 读图指引（"横轴为…，纵轴为…，气泡大小为…"）。
- 估算类数据加脚注（来源、口径、修订入口）。
- 口径开关旁给一句人话（"已排除异常样本"）。

## 9. 动效规范

| 场景 | 时长 / 曲线 | 说明 |
| --- | --- | --- |
| hover / 颜色变化 | 150ms ease-out | 图标、行、按钮 |
| 卡片进入 | 240ms ease-out，位移 8px + 透明 | 首屏一次性 |
| 数字变化 | 250ms 翻牌 | 仅数值更新 |
| 图表绘制 | 600–800ms ease-out | 首次渲染；切换筛选 300ms |
| 浮层 | 180ms 缩放 0.98→1 + 淡入 | 抽屉 220ms 横向位移 |

- 全部支持 `prefers-reduced-motion: reduce` → 直接跳到终态。
- **禁止**：无限循环动画、视差、自动轮播。

## 10. 可访问性基线

| 项 | 现状参考 | 规范要求 |
| --- | --- | --- |
| 语言声明 | `lang="en"` ✅ | 多语言时随切换更新 |
| 地标 | `header` / `main` / `nav[aria-label]` ✅ | 侧栏补 `aside` 或 `nav` |
| 图标按钮命名 | 均有 `aria-label` ✅ | 保持 |
| 焦点环 | `ring-2` ✅ | 对比度不足时改用 2px `#93C5FD` |
| 表格语义 | 榜单用真实 `<table>` ✅；矩阵用 `div` ⚠️ | 矩阵补 `role="grid"` 或提供表格视图 |
| 当前页标记 | `aria-current="page"` ✅ | 保持 |
| 跳转链接 | 无 Skip to content ❌ | 首元素加 skip link |
