> 来源：对一套成熟赛事数据看板的 18 个模块做完整走查后，**剥离行业术语、只保留功能与交互结论**，抽象为一套可直接用于其他数据产品的规范。

## 一句话结论

> 高密度看板的本质不是"放更多图表"，而是**统一的卡片语法**：一卡一问、控件贴数据、颜色即编码、口径常驻。

## 术语对照

规范正文只使用左列术语。右列是它在不同产品中的常见落点，可直接替换，不必改动结构。

| 通用术语 | 含义 | 在其他产品中通常是 |
| --- | --- | --- |
| 对象 / 实体 | 被分析的最小单位 | SKU、账户、主机、门店、候选人、设备 |
| 组织 / 分组 | 对象的归属集合 | 部门、渠道、租户、Region、供应商 |
| 场次 / 事件 | 一次有边界的过程记录 | 活动、批次、发版、交易日、工单 |
| 周期 / 时间范围 | 统计的时间窗口 | 财季、季度、版本周期、近 30 天 |
| 子场景 / 会话 | 事件内的阶段划分 | 环节、阶段、渠道、实验组 |
| 指标值 / 分值 | 被比较的量化结果 | GMV、得分、健康分、转化率 |
| 排名榜 | 按指标排序的列表 | 销售榜、性能榜、风险榜 |
| 名录 / 档案 | 实体清单与详情页 | 客户档案、设备档案、商品库 |
| 明细时序 | 高粒度的时间序列 | 秒级监控、逐笔行情、日志时间线 |
| 配额与消耗 | 额度使用与超额 | 许可证、库存、Token 配额、带宽 |
| 变更记录 | 随时间发生的调整 | 配置变更、发版记录、工单流 |
| 损耗 / 成本 | 负向累计值 | 故障成本、退款、停机损失 |
| 多维属性矩阵 | 多对象 × 多属性的评分表 | 供应商评分、门店画像、风险矩阵 |
| 异常状态 | 非正常结束 | 失败、超时、取消、熔断、跳过 |

## 采集说明与边界

- 原页面为 Next.js 应用，暗色主题为默认，数据为演示数据。
- 图表由客户端渲染，部分参考截图在静态采集时尚未完成绘制；文档中相关处标注为"加载态缺失"的改进项，而非渲染缺陷。
- 时间表模块依赖 WebGL 地图，在无头浏览器中加载失败，其结构依据服务端文本与文案还原。
- 实时监控模块仅能观察到空闲态（纯文本加载提示）。
