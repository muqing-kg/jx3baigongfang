# 数据看板 · 模块交互规范

> 配套：[01-设计规范.md](./01-设计规范.md)
> 覆盖 18 类**功能模块原型**（与行业无关）。每个模块给出：功能定位 → 页面结构 → 交互控件 → 反馈状态 → 可复用模式 → 风险。
> 读者可按"你的产品需要哪个模块"直接取用，而非照着某个行业的产品抄。

---

## 0. 全局交互模型

### 0.1 四种"到达答案"的路径

| 路径 | 模块类型 | 交互特征 |
| --- | --- | --- |
| **读榜单** | 排行榜、效率指标、成本损耗 | 表格优先，排序即分析，行可下钻 |
| **看趋势** | 累计演化、明细时序、变更记录 | 图表 + 时间轴，hover 出值 |
| **做对比** | 双对象对比、分布稳定性、属性矩阵 | 选择器 + 成对/多序列可视化 |
| **查事实** | 时间表、结果汇总、名录、档案 | 浏览卡片 → 详情面板 / 详情页 |

### 0.2 统一页面骨架

```
页面标题 + 一句话口径说明        [周期 2026] [对象筛选 N] [维度筛选 N]
──────────────────────────────────────────────────────────────
KPI 条（0–6 张）→ 主图表区（1–4 张卡）→ 明细表/次级图表 → 脚注
```

### 0.3 交互一致性规则

1. **筛选器只出现在两类位置**：页面工具条（影响全页）或卡片头部（影响本卡）。
2. **所有图表卡右上角都有导出**，行为一致。
3. **"口径修饰"用开关/滑杆**，不用下拉（排除异常、仅算有效、高亮重点、拆分维度）。
4. **互斥视图用分段控件**（全部 / 子集 A / 子集 B / 子集 C）。
5. **数字变化只播一次动画**。
6. **行 hover 统一为 6% 白色叠加**，可下钻的行带右箭头 `›`。

## 1. 总览页（Overview）

| 项 | 内容 |
| --- | --- |
| 功能定位 | 30 秒内回答：现在进行到哪、最近发生了什么、去哪儿深入 |
| 结构 | ① 状态卡（倒计时/当前阶段，2×1）② 日程卡 ③ 关键指标（1 个）④ 三项周期指标 ⑤ 关注/订阅条 ⑥ 专题图卡 ⑦ 对象排行 Top 10 ⑧ 分组排行 Top 10 ⑨ 动态流（分类筛选） |
| 控件 | 周期选择器；卡片整块可点（跳转对应模块）；"查看完整排行 →"文字链；动态流分类（全部 / 分组 / 对象 / 新进 / 场次 / 属性） |
| 反馈 | 倒计时逐秒刷新；指标卡带环比 `+3.73% 较上周期`；动态卡显示日期 + 场次标签 |
| 优点 | 单屏完成"状态 + 入口"；每个卡片都是深链入口，无死胡同 |
| 风险 | 倒计时依赖客户端计时器，容器尺寸变化时数字区可能空白；动态流内部滚动区过矮（约 500px），需二次滚动 |
| 模式 | P11 KPI 条、P03 卡片控件、P12 下钻 |

**细节**：倒计时为"天/时/分/秒"四段，10px 大写标签置于数字下方；日程卡用**矢量轮廓插画**而非真实地图，加载成本远低于地图组件——值得复用的"轻量装饰"手法。

## 2. 实时监控（Live Monitor）

| 项 | 内容 |
| --- | --- |
| 功能定位 | 活动进行中盯实时排名/指标、事件流、异常 |
| 结构 | 连接态 → 主榜 + 侧栏（布局切换、分段统计、消息流） |
| 控件 | 布局切换、连接状态指示 |
| 状态 | 空闲时显示 `Loading... / Establishing Connection...`（纯文本），是唯一没有骨架屏的模块 |
| 优点 | 会话感知：无活动时不报错，静默等待 |
| 风险 | ① 无骨架屏与重连分级 ② 空态无"下一场时间"出口 ③ 纯文本加载在弱网下无法判断是否卡死 |
| 模式 | P15 状态三态（缺失） |

**改进**：连接状态用三色点（连接中/已连接/断开）+ 最后更新时间；空态给出"下一场：xx 时间"倒计时与"查看时间表"按钮。

## 3. 时间表（Calendar / Schedule）

| 项 | 内容 |
| --- | --- |
| 功能定位 | 找到下一场/某场时间，了解场地与流程安排 |
| 结构 | 按序号排列的事件行卡（编号 + 状态徽标 + 属性徽标 + 地区 + 日期区间）；点击展开详情面板 |
| 状态徽标 | `已完成`（灰）/`进行中`（高亮）/`已取消` |
| 详情面板 | 场地示意图（第三方地图，失败时降级提示）、场地属性（类型/数量/长度/落差）、流程时间表、**时区切换** |
| 关键交互 | **时间制式切换**：默认本地时间，一键切当地时间，按钮上直接显示偏移量 |
| 辅助 | `上一场` / `下一场` 快速定位 |
| 风险 | 强依赖第三方地图，token 缺失时整块不可用（只给文字提示，无静态图兜底）；无"加入日历（ICS）" |
| 模式 | P08 详情面板、P02 页级筛选 |

**可复用结论**：跨时区的日程必须提供"我的时间 / 当地时间"二元切换，并把偏移量写在按钮上，而不是让用户自己换算。

## 4. 结果汇总（Results）

### 4.1 周期总览

| 项 | 内容 |
| --- | --- |
| 结构 | 统计范围分段（`全部 / 子集 A / 合并`）→ 6–8 张纪录卡（最多第一、最多前三、最佳平均、最大提升、最大/最小差距）→ 分组总量条 → 总表 → 按场次的矩阵热力图 |
| 总表 | 序号、场次（地区+名称）、日期、若干关键结果列；**单元格背景 = 实体品牌色**，一眼看出谁在主导；行尾 `›` 进入详情 |
| 热力图 | 25 个对象 × 23 场次，格内为数值或名次；`范围切换` + `显示切换（数值/名次）` + 颜色图例 + 导出 |
| 交互 | hover 单元格出 Tooltip（对象 + 场次 + 明细）；首列 sticky |
| 风险 | 23 列在 1344px 内容区必须横向滚动，无滚动提示；图例藏在卡片底部；空值（未参与）用深底小圆点，对比度低 |
| 模式 | P04 表格、P05 矩阵、P06 图表卡、P12 下钻 |

### 4.2 单场详情

- 子场景切换：多个阶段（如准备 / 预选 / 正式 / 汇总）。
- 主表：名次、对象、分组、最佳值/总时长、差距（对第一 / 对前一名 / 落后量）。
- 附加：异常说明（晋级、扣减、替换）、历史记录对比、`排除离群值` 开关、演进曲线。
- 亮点：扣分、替补、临时对象均有徽标与解释弹层，**把"非标准情况"当一等公民**，而不是塞进脚注。

## 5. 对象排行榜（Ranked List · 个体）

| 项 | 内容 |
| --- | --- |
| 结构 | 左 4 列（头名卡 + 25 行榜单）/ 右 8 列（4 张分析卡） |
| 头名卡 | 实体品牌色渐变 + 头像 + 称号 + 总分；视觉锚点 |
| 榜单 | 序号 / 对象 / 指标值 / 变化（`↑1 ↓1 –`）；行 hover；表头右侧导出 |
| 分析卡 | ① 累计值演化（折线，可叠加对比期）② 排名演化（Bump 图）③ 多维统计（多选 pill 叠加柱状）④ 构成分布（总体堆叠条 + 按场次堆叠条） |
| 交互 | 点击行 → 个体详情；所有卡片可导出；周期切换重算整页 |
| 风险 | 变化列可能同时出现 `-0` 与 `–`，语义不清；25 行在左栏需内部滚动，滚动条默认隐藏 |
| 模式 | P04、P06、P12、P11 |

---

## 6. 分组排行榜（Ranked List · 组织）

- 与对象榜**结构完全同构**：头名卡换成分组与代表图，11 行榜单，同样的演化、排名、统计、构成四张卡。
- 一致性价值：用户学会一个页面即会用另一个；图表位置、控件位置、导出位置完全对应。
- 差异点：多维统计用**分组柱状**（同组多指标并列），因为对象只有 11 个，横向空间足够。
- 风险：排名演化图右侧只有实体图标无名称，新用户需 hover 才能确认。

**可复用结论**：同类实体（个人/组织、SKU/渠道、主机/集群）的页面应保持"镜像结构"，仅替换对象维度。

## 7. 对象名录（Directory · 个体）

| 项 | 内容 |
| --- | --- |
| 结构 | 3 列 × N 行卡片；页头帮助入口 + 周期筛选 |
| 卡片 | 实体品牌色渐变底 + 品牌图形水印 + 头像/主图（右侧裁切）+ 名称/分组/编号 + 2 项评分 + 等级徽标（A/B/C/D/F） |
| 交互 | 整卡可点 → 个体详情；`新进` 徽标；缺图时回退纯文本编号 |
| 信息设计 | 把抽象的"综合评分"压缩成 `分数 + 等级`，并用帮助入口解释——**评分必须可解释** |
| 风险 | 卡片信息量不一致（有的显示编号、有的显示标签）；评分不可排序，无法"按评分排" |
| 模式 | P10 实体卡网格、P14 渐进披露 |

## 8. 组织名录（Directory · 组织）

| 项 | 内容 |
| --- | --- |
| 结构 | 3 列卡片，含品牌色渐变、代表图、编号、2 个成员头像 |
| 交互 | 点击 → 档案页（全称、所在地、负责人、技术负责人、型号、首次记录、累计成绩、简介展开/收起） |
| 图集 | 图集入口 → 全屏灯箱：←/→ 键、滑动手势、底部缩略图、Esc 关闭 |
| 优点 | 图片统一走 CDN 参数化裁剪（`w500-h200-fcrop-q85`），不同卡位复用同一原图 |
| 风险 | 卡片数量不能被 3 整除时最后一行留白（`auto-fill` 可优化） |
| 模式 | P10、P09 灯箱 |

## 9. 个体详情（Profile）

| 项 | 内容 |
| --- | --- |
| 入口 | 排行榜行点击、名录卡点击、页头对象选择器 |
| 结构 | ① 身份条（头像、名称、分组、当前名次）② 4 张**关系型** KPI（对下一名领先、分组占比进度条、对同组同伴领先、均值对比）③ 4 张计分卡（各带迷你柱 + 分布图例）④ 能力/表现雷达或径向 ⑤ 达成率环形（90%）⑥ 排名分布横条 ⑦ 累计值演化对比 ⑧ 起点→终点流向（桑基）⑨ 逐场明细条 |
| 交互 | 周期与对象双选择器；每卡导出；hover 出值 |
| 优点 | 从"结果"到"过程"叙事完整；KPI 用**对比对象**定义（对下一名 / 对同组），比孤立数值有信息量 |
| 风险 | 页面过长（>2400px），无页内锚点导航；流向图节点色与品牌色不同源 |
| 模式 | P11、P06、P07 |

## 10. 双对象对比（Head-to-Head）

| 项 | 内容 |
| --- | --- |
| 功能定位 | 比较两个对象在多个维度上的胜负关系 |
| 结构 | 页头 4 个筛选（周期、分组、对象 A、对象 B）+ 一句话说明 → **热门对比卡片**（预设组合）→ 左右双栏对比（维度 A / 维度 B）→ 明细点图 |
| 对比条 | 发散条形：左蓝右橙（或双方品牌色），比分永远居中 |
| 分段 | `合并 / 子集 A / 子集 B` |
| 点图 | 每个对象一行，散点表示每次差值，中心线 0，左右对称轴 |
| 优点 | 先给"热门对比"降低冷启动成本；比分（`20 vs 3`）始终在视觉中央 |
| 风险 | 双栏在 <1280 时堆叠，失去左右对照意义；无"交换对象"快捷按钮；无平局展示 |
| 模式 | P07 对比选择器、P13 多选、P05 |

## 11. 分布稳定性（Distribution）

| 项 | 内容 |
| --- | --- |
| 功能定位 | 看谁"忽高忽低"——用分布而非平均值 |
| 结构 | 2×2 箱线图（四个子场景的排名分布） |
| 控件 | `排除异常` 开关、周期选择；图内参考线（达标线、入围阈值） |
| 优点 | 用箱线图 + 阈值线，把"稳定性"翻译成"箱体高度 + 是否越线"，专业且可读 |
| 风险 | 标签仅用 3 字母缩写，新用户不认识；无排序（按中位数/离散度）；四分位未解释 |
| 模式 | P03 卡片控件、P14 解释层 |

## 12. 明细时序（Event Time Series）

| 项 | 内容 |
| --- | --- |
| 结构 | 左侧 Top 20 明细表 → 右侧逐点演化（多线）→ 分布箱线 → 原始散点小倍数 → 排名演化折线 |
| 控件 | 三个筛选（周期 / 场次 / 对象）+ `明细筛选`：`仅有效样本` 开关、`离群阈值` 滑杆（107%）、`高亮：关 / 个人最佳 / 最优` 分段 |
| 优点 | "剔除脏数据"与"离群阈值"是专业分析必需品，本产品把统计学参数直接暴露且实时生效 |
| 风险 | 滑杆单位无解释；筛选变更后图表动画重播，长列表下易迷失；无"差值（delta）"视图 |
| 模式 | P03、P06、P12 |

## 13. 效率 / 耗时指标（Duration Metrics）

| 项 | 内容 |
| --- | --- |
| 结构 | 6 张 KPI（最优单次、对象榜/分组榜、分组均值最优、最稳定 ±、总体均值、累计时长）→ Top 20 表（含素材/回放列，第一名高亮）→ 分组箱线 → 均值趋势（`按分组拆分` 开关）→ 4 张条形榜 |
| 交互 | 周期切换；每卡导出；拆分开关切换多序列/单序列 |
| 优点 | 统一单位为秒、统一 2 位小数，保持可比；榜单一律水平条 + 数值右置 |
| 风险 | 素材列为空时留白（应用占位图标）；箱线图极端离群值拉长 Y 轴（11.0s），压缩主体 |
| 模式 | P11、P04、P06 |

## 14. 变更记录（Change Analytics）

| 项 | 内容 |
| --- | --- |
| 结构 | 页头 4 个多选筛选（周期、分组 11、类型 6、原因 13）→ 4 个概览块（按分组条形、类型环形、原因环形、条目清单）→ 分组×场次堆叠条 → 时间散点（气泡=数量，`高亮重点` 开关、点击气泡过滤）→ 累计变更折线 |
| 控件 | 多选 + 搜索（条目清单）、开关、散点点击过滤 |
| 优点 | 从"总量"到"结构"到"时间分布"三层递进；可搜索清单让长尾维度变可用 |
| 风险 | **布局缺陷**：右栏清单跨行覆盖图表区；散点过滤后无"当前筛选"回显；颜色同时编码分组与类型，易混 |
| 模式 | P13 多选、P05 散点、P03 |

## 15. 配额与消耗（Quota & Consumption）

| 项 | 内容 |
| --- | --- |
| 结构 | 主矩阵：25 对象 × 7 配额项，格内为大号用量 + 每次记录小圆点，颜色按超额程度红/黄；`合计` 列；右侧两张条形榜（按对象、按分组）→ 下方"扣减明细"按场次分组 |
| 交互 | 图例/说明切换、导出；明细组显示变更项标签、扣减量、影响结果 |
| 优点 | 把规则型数据做成"一眼看出谁爆仓"的矩阵；扣减明细按场次分组，符合业务叙事 |
| 风险 | 小圆点含义无图例；红/黄阈值未说明；列头缩写对新手不友好 |
| 模式 | P05 矩阵、P04 |

## 16. 成本 / 损耗（Cost & Loss）

| 项 | 内容 |
| --- | --- |
| 结构 | 左 4 列：25 行损失榜（金额右对齐、分组图标）；右 8 列：分组成本、累计对象、累计分组、按场次成本 4 张图 |
| 控件 | 周期 / 对象 / 分组筛选 |
| 可信度设计 | 表下脚注：数据为估算而非官方，标注来源，并提供 `7 处修订` 入口 |
| 优点 | "非官方数据"主动声明来源与修订记录，是数据产品诚实性的范本 |
| 风险 | 图表首屏绘制慢且无骨架占位；金额未用千分位简化（`$2,443,000` vs `$611K`），同一产品内口径不一致 |
| 模式 | P15、P16 可信度脚注 |

## 17. 多维属性矩阵（Attribute Matrix）

| 项 | 内容 |
| --- | --- |
| 结构 | ① 属性热力图（7 项特性 × 23 对象，1–5 分，暖色刻度），`排序：默认 / 各指标`，可导出 ② 相似度气泡散点（X=属性 A 占比，Y=属性 B 占比，气泡=规模，色=压力），带 3 行读图指引与图例 ③ 三张横向条形（数量/距离/长度） |
| 交互 | 排序下拉（按任意特性排序会重排矩阵列序）、导出 |
| 优点 | 把主观概念量化成 7 维 + 相似度地图；图下解释"横轴读作…"，降低门槛 |
| 风险 | 热力图仅数字无语义标签（1 与 5 意味什么）；三张条形在窄屏被压缩；无对象筛选/高亮联动 |
| 模式 | P05、P06、P14 |

## 18. 更新日志（Release Notes）

- 时间倒序的版本条目，含日期与变更描述，无筛选与搜索。
- 作用：与"反馈"外链组成产品运营闭环，向用户证明仍在迭代。
- 风险：无版本锚点、无订阅入口（RSS / 邮件）。

## 19. 可复用模式库（P01–P16）

## 20. 关键任务流

### 20.1 "最近一次结果如何，过程怎样"

```
总览（状态卡 / 最近场次）
 → 结果汇总（定位该场次行，看关键结果列的实体色）
 → 点击行尾 › → 单场详情
 → 查看差距 / 异常说明 / 演进曲线
```
目标：≤ 3 次点击。现状符合。

### 20.2 "比较两个对象"

```
双对象对比 → 选择对象 A / B（或点热门对比卡）
 → 看维度 A 比分 → 切维度 B → 看明细点图分布
 → 需要细节时点对象 → 个体详情
```

### 20.3 "审计某分组的变更节奏"

```
变更记录 → 分组多选（选 1 组）→ 类型/原因收窄
 → 分组×场次堆叠条看节奏 → 散点看时间分布（开高亮重点）
 → 右栏清单搜索关键词验证具体条目
```

### 20.4 失败体验（现状）

- 筛选条件不写入 URL：分享链接丢失上下文；浏览器后退会退出模块而非撤销筛选。
- 图表空白时无占位：用户无法区分"加载中"与"没有数据"。

## 21. 响应式与移动端

| 断点 | 变化 |
| --- | --- |
| ≥1280 | 侧栏 256 + 内容 12 列，卡片 3 列 |
| 1024–1279 | 侧栏保留（可折叠），卡片 2 列，双栏图表堆叠 |
| 768–1023 | 侧栏折叠为图标，页头出现汉堡菜单，KPI 2 列 |
| <768 | 侧栏变抽屉；卡片 1 列；表格横向滚动（首列 sticky） |

移动端要点：
- 导航改抽屉 + 全屏菜单，页面标题进 header。
- 表格优先"保留核心 4 列 + 横向滚动"，不折叠成卡片（数据对比场景折叠更差）。
- 图表高度降为 220–260px，Tooltip 改为点击触发（无 hover）。
- 触控目标 ≥ 44px（桌面侧栏项 36px，移动端需放大）。

## 22. 验收清单

**布局**
- [ ] 侧栏 256 / header 64 / 内容 max 1920 落地
- [ ] 12 列栅格 + 16px gap，卡片等高
- [ ] 页面内边距 24（桌面）/16（移动）

**控件**
- [ ] 可点元素 32–36px 高，圆角 6px
- [ ] 筛选器显示已选计数，提供 Clear all
- [ ] 图表卡右上角有导出
- [ ] 开关/滑杆旁有口径说明

**数据**
- [ ] 数字等宽对齐，单位随数值缩放
- [ ] KPI 有对比基准（上期 / 同类 / 同组）
- [ ] 颜色有图例，阈值有说明
- [ ] 非官方数据有脚注与来源

**状态**
- [ ] 每个数据块有骨架屏
- [ ] 空态给出下一步动作
- [ ] 错误是卡片级内联，不整页白屏

**交互**
- [ ] 筛选写入 URL，可分享、可后退
- [ ] 浮层 Esc 关闭 + 焦点返回
- [ ] 键盘可达，图表有"查看数据表"替代

**一致性**
- [ ] 同类页面（个体/组织）结构镜像
- [ ] 同一指标在所有页面用同一图表类型
- [ ] 品牌色不参与数据编码

## 23. 总评

**做得好的三件事**

1. **把"分析"变成界面**：不是把数据堆上页面，而是每张卡回答一个具体问题（谁最优、谁最稳、谁超额）。
2. **专业口径显性化**：排除规则、离群阈值、入围阈值、估算脚注——这些细节构成产品的可信度壁垒。
3. **结构同构**：个体榜与组织榜、效率指标与变更记录的卡片排布高度一致，学习成本低。

**最需要改进的三件事**

1. **状态设计缺失**：加载/空态/错误三态不成套，图表空白时无解释。
2. **可分享性缺失**：筛选不进 URL，深链只有页面级。
3. **可访问性欠账**：矩阵用 div、无 skip link、图表无键盘路径、无 aria-live。

**对后续项目的核心启示**：数据密度不靠"多放"，而靠"每块只回答一个问题 + 统一的卡片语法 + 常驻口径说明"。这套语法可迁移到任何高密度数据场景。
