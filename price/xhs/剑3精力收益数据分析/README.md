# 剑3精力收益数据分析 · 小红书图文包

用「双梦（梦江南）」物价 + **50% 制造暴击**，重算《剑网3》苍生铸世 50 级的 154 条制造配方，输出 7 张 1080×1440 小红书配图、可直接发布的文案和数据明细。

## 先看结论

| 指标 | 0% 暴击 | 50% 暴击 | 100% 暴击 |
| --- | ---: | ---: | ---: |
| 盈利配方 | 92 / 154 | **124 / 154** | 134 / 154 |
| 中位精力收益 | 0.61 金/精力 | **5.64 金/精力** | 11.61 金/精力 |

- 50% 暴击让 **32 条配方由亏转赚**，但仍有 **20 条**即使 100% 暴击也亏。
- 「可成交榜」（产物 + 全部材料都有拍卖报价，85 条）TOP1：**膘然心动 95.3 金/精力**。
- 账面第一的 **归营旌 299.1 金/精力**，4 个半成品都没有拍卖报价；自己补做 600 精力，折算约 **72.7 金/精力**。
- 前 12 名账面榜里，**0 条**全链路有实时报价；玄元系列成品也是示例价。

## 数据与口径

- **服务器**：双梦 = 梦江南（`s_mengjiangnan`）。双梦镇由梦江南、如梦令、枫泾古镇合并而来，玩家约定俗成称“双梦”。
- **数据源**：`https://cherishxie.github.io/JX3-AH-Calculator/` 线上版，2026-11-19 14:51 抓取；页面数据时间戳为 **2026-11-19T14:22:11+08:00**。线上快照比仓库内 `assets/data.js`（12:06）更新，因此使用线上快照。
- **范围**：5 类制造技艺（锻造 45 / 缝纫 39 / 制药 22 / 烹饪 26 / 梓匠 22），共 154 条；不含 21 条采集。
- **成本**：Σ（材料数量 × 材料单价）+ 手续费；材料与产物均用双梦价格，有拍卖报价优先用报价，无报价回退工具示例价。
- **税**：售价扣 5% 交易税。
- **暴击 50%**：按“额外产出一份”建模，期望产出 = 基础产出 × 1.5；材料成本不变。这不是官方保底，只是本次分析的假设。若你的暴击倍率不同，可按 `产值 ×(1+暴击率×倍率)` 调整。
- **全链路有报价（85 条）**：该配方的**产物**和**全部材料**都能在 `serverPrices.s_mengjiangnan` 找到 >0 的拍卖报价。其余 69 条至少有一端是示例价，单独标注。
- **归营旌全链路**：成品有报价，但 定营铁桩 / 同袍营幡 / 安营炊鼎 / 定魂丹砂 无报价。按“自己补做这 4 个半成品、其余材料按报价买入”展开：总精力 = 120×5 = 600；材料成本 6,284；利润 43,591；≈72.7 金/精力。未把半成品暴击的额外产出算进去，是偏保守的口径。

## 复现

```bash
cd "xhs/剑3精力收益数据分析"

# 1. 计算：读 data/snapshot.json，写 summary.json / 数据明细.csv
python3 analysis.py

# 2. 渲染：需要 playwright + chromium + numpy
python3 generate.py
```

`generate.py` 会把 `cards/*.html` 用 Chromium 以 1080×1440 截图，输出 7 张 PNG。

## 已知边界

- 未建模销量、市场深度、成交速度、署名溢价、跨服交易；榜单是“单位精力收益”，不是“保证卖出”。
- 价格会随行情变化；示例价不是成交承诺。
- 暴击 50% 是假设值；游戏内实际暴击率受等级突破、配方等因素影响。
- 归营旌、玄元系列等低频/高价物品，样本少，适合当上限参考，不适合直接囤货。
