# 剑3精力收益数据分析 · 设计规范版

按项目 [`docs/design/01-设计规范.md`](../../docs/design/01-设计规范.md) 与 [`02-模块交互规范.md`](../../docs/design/02-模块交互规范.md) 重做的 7 张 1080×1440 小红书配图。

## 设计口径

- **亮色工作台**：页面底 `#F5F5F5`，卡片 `#FFFFFF`，1px `#E2E8F0` 描边，8px 圆角，无阴影。
- **字阶**：系统无衬线；页面标题 30/38，卡片标题 16/24，正文 12–14/20，微标签 10–12/16，KPI 32/38。
- **颜色即编码**：5 类技艺使用 `chart-1..5` 数据色；正向 `#2E9E78`、负向 `#E11D48`、峰值 `#B36BFF`；品牌红 `#E10600` 只出现在 Logo。
- **一卡一问**：KPI 条 → 主图表卡 → 明细表 / 行动建议 → 口径脚注。
- **控件贴数据**：页面右上是作用域（`可成交 85 / 全部 154`），卡片右上是最多两个控件（徽标 + 导出）。
- **口径常驻**：每张图有副标题、单位、扣税/暴击/样本口径；页脚有数据快照与“非官方”声明。
- **图表**：水平条形、堆叠条、箱线图、散点；不用双 Y 轴、不用 3D、不用饼图。

## 数据与口径

- **服务器**：双梦 = 梦江南（`s_mengjiangnan`）。双梦镇由梦江南、如梦令、枫泾古镇合并而来。
- **数据源**：线上版 `https://cherishxie.github.io/JX3-AH-Calculator/`，2026-11-19 14:51 抓取；数据时间戳 **2026-11-19T14:22:11+08:00**。
- **范围**：锻造 45 / 缝纫 39 / 制药 22 / 烹饪 26 / 梓匠 22，共 154 条制造配方；不含 21 条采集。
- **成本**：Σ（材料数量 × 材料单价）+ 手续费；有拍卖报价优先，无报价回退工具示例价。
- **税**：售价扣 5%。
- **暴击 50%**：按“额外产出一份”建模，期望产出 ×1.5；不是官方保底。
- **可成交 85 条**：产物 + 全部材料都有 >0 拍卖报价。
- **归营旌全链路**：4 个半成品无报价，按自己补做展开；总精力 600，材料成本 6,284，利润 43,591，≈72.7 金/精力；未计半成品暴击额外产出，偏保守。

## 复现

```bash
python3 analysis.py   # 读 data/snapshot.json，写 summary.json / 数据明细.csv
python3 generate.py   # 需要 playwright + chromium + numpy，输出 7 张 PNG
```
