## 设计口径（v3）

- **先问问题，再给答案**：上半部只做一件事——把目标用户心里那句话放大：「今天精力做什么？」。`今天精力` 108px 铺垫，`做什么？` 228px 做主视觉，红色问号单独成色块。
- **答案卡**：下半部是一张深色榜单卡（`#0B1424`），与米白纸面形成强对比；第一行 `归营旌 175.25` 用 126px 高的高亮行 + 双层手绘红圈直接回答“做什么”，2/3 名做备选。
- **数据可信**：卡脚注 `共 171 条 · TOP1 175.25 = 中位 1.33 × 132`，保留 `示例价` 角标；不写“实时行情”。
- **为什么不是「精力别乱花」**：这句话是常识，用户已经被教育过了；目标用户缺的是“做什么、哪个更赚”的决策答案，所以标题换成他们真正会问的问题。
- **3:4 安全区**：核心信息集中在中央 1080×1080；主页 1:1 裁切后仍保留标题、榜单和品牌名（卡脚注）。
- 声明：非官方玩家工具、示例价可校准；不含官方 Logo、角色、截图。

## 使用建议

1. 创服平台图标优先上传 `icon-1024.png`；若要求 512，使用 `icon-512.png`。
2. 笔记首图优先使用 `cover-3x4-1080x1440.png`；平台横版卡片使用 `cover-16x9-1200x675.png`。
3. 上传前做两级预览：240px 宽缩略图里确认「做什么？」「175.25」仍清楚；再按 1:1 居中裁切（`sips -c 1080 1080`）确认标题和榜单不丢。
4. 不要叠加平台自带的头像/昵称/点赞按钮；重要内容已避开底部 200px。

## 备注

- 封面数字对应数据版本 `v3.3`（2026-11-18）：`154` 条制造配方、`171` 条总配方（含 17 个当前版本采集点）、`263` 项物品、`17` 个服务器；TOP1 `175.25`、全站中位 `1.33`、约 `132` 倍。
- 数据从 v3.1 同步到 v3.3 后，封面已从 `48.98 / 0.67 / 73 倍` 更新为 `175.25 / 1.33 / 132 倍`；再更新数据时请同步改 `cover-*.svg` 的三行名称、精力、数值、条宽和脚注。
- 导出命令：
  ```bash
  rsvg-convert -w 1080 -h 1440 cover-3x4.svg -o cover-3x4-1080x1440.png
  rsvg-convert -w 1200 -h 675  cover-16x9.svg -o cover-16x9-1200x675.png
  ```
- v2（浅色榜单卡 +「精力别乱花」）和 v1（深色仪表盘）已归档，保留用于 A/B 对比；确认新版数据后可直接删除。
- 所有图形均为本项目自绘；中文使用系统字体 `Songti SC / PingFang SC`，仅栅格化为 PNG 使用。

## 与自动物价的关系

`scripts/update-jx3-prices.mjs` 自动更新数据与 minitool zip，但**不会自动改封面**。封面是发布时的视觉快照，自动价格更新后 TOP/中位数字可能变化；需要同步封面时，重新导出 `cover-*.svg` 并在上传前替换。
