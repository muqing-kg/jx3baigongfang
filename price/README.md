# 剑网三物价助手 · 剑网3「苍生铸世」生活技艺成本与精力收益计算器

面向《剑网3》当前 **苍生铸世（50 级）** 版本的生活技艺经营工具：选服务器、维护本服价格、编辑/新增配方、计算材料成本与精力收益，把所有制品放在同一张精力收益榜上对比，并回溯各区服物价走势。

> 设计遵循 `docs/design/01-设计规范.md`、`docs/design/02-模块交互规范.md` 与 `docs/design/data-chart/`：暗色工作台、12 列栅格、一卡一问、控件贴数据、颜色即编码、状态三态、口径常驻。

> 在线版：<https://cherishxie.github.io/JX3-AH-Calculator/> · 开发预览：<https://cherishxie.github.io/JX3-AH-Calculator/dev/>（带 DEV 标识） · 小工具包：<https://cherishxie.github.io/JX3-AH-Calculator/downloads/jx3-minitool.zip>
>
> **当前发布（2026-11-20）**：新增「物价走势」，支持历史节点、物品/材料筛选、价格分布、涨跌红黑榜、热力图和图表图片导出；同步修复行情自动更新与移动端更新检查。

## 快速开始

静态站点，无构建、无外部依赖，数据保存在浏览器 `localStorage`。

```bash
cd JX3-AH-Calculator
python3 -m http.server 8931
# 打开 http://127.0.0.1:8931
```

也可以直接打开 `index.html`。建议使用本地服务器：`file://` 下部分浏览器会限制 `localStorage` 持久化。

在线版支持 PWA：可添加到主屏幕；新版本会自动检测并在页面底部提示，更新前可预览更新内容。

### 核心操作

- **选择服务器**：右上角服务器下拉，17 个当前服务器（含新服「九天」），支持新增自定义服务器；每个服务器独立价格空间。
- **默认亮色主题**：首次打开使用亮色；右上角可切换暗色并记住选择。旧版本从未手动选过主题的缓存会自动迁移到亮色。
- **行情静默更新**：价格机器人只更新 `serverPrices` 和价格字段，页面内静默刷新，不弹 PWA“代码新版本”提示；只有应用壳版本变化才提示更新。
- **编辑配方**：配方表行 → 详情抽屉 → 编辑；可改名称、品阶、等级、精力、手续费、产物、材料；内置配方可「恢复示例」。
- **新增配方**：生活技艺页右上角「新增配方/新增采集点」；可新建产物或材料物品，保存后进入价格库补价。
- **修改精力**：每条配方/采集点的「单次精力」均可编辑；设置中可改新建配方默认精力与精力预算。
- **五行石公式**：五行石页可直接改 1-8 级价格、编辑任意合成公式（材料、数量、加工费、精力、产出概率），并单独校准 7/8 级爆率。
- **计算与对比**：成本 = Σ材料 + 手续费；利润 = 产值 − 成本；精力收益 = 利润 ÷ 精力；支持「市场价 / 取最低（市场价与自制成本逐层取低）」两种口径。
- **突破升级**：分析页底部入口卡 → 独立页 `/breakthrough`；按当前服物价为 8 项技艺排「1→50」路线，30/35/40/45 级晋秩材料可展开查看自制配方与拍卖价，三种维度一键切换。
- **物价走势**：分析 → 物价走势；按历史节点回溯本服报价，筛选栏支持全部技艺/全部类型、物品多选/全选与价格区间，物品搜索放在多选面板内，移动端筛选栏默认收起；跨技艺材料按实际配方用途展示。不同物品独立配色，价格分布默认用价格指数（首点=100）避免价格跨度压缩趋势，每个图表标题右侧可单独切换原始金币（对数）；展示最低/最高、25–75% 箱体与中位线，价格散点按物品平铺，点击物品看单品折线；另提供涨跌红黑榜（前 10 + 全量）与区间涨跌热力图，各图表可下载 PNG；原始数据按节点折叠，可展开查看并导出 CSV；顶部行情条支持手动检查远程物价，dev 预览使用生产行情数据。
- **导出**：每个图表可导出 PNG；分析/价格表可导出 CSV；设置中可导出/导入完整 JSON 备份。

## 计算口径

```
材料成本 = Σ（材料数量 × 材料单价）
总成本   = 材料成本 + 手续费
产值     = Σ（产物数量 × 产物单价）
利润     = 产值 − 总成本
精力收益 = 利润 ÷ 精力
毛利率   = 利润 ÷ 产值
```

- **市场价口径**：材料按填入的本服单价。
- **取最低口径**：每个材料取 `min(市场价, 自制成本/产出数量)`，递归计算，带循环保护。**它只优化材料成本，不会把自制中间产物所消耗的精力计入最终配方的精力分母**；若要比较全链路精力效率，请用市场价口径或把中间产物合并成一条自定义配方。
- **采集**：按单次采集点的多产出计算；游戏内采集消耗体力，本工具按精力口径统一折算，单次精力可编辑。
- **交易税/暴击/署名**：交易税默认按售价 5% 扣除，可在设置中修改；暴击额外产出与署名溢价仍不计，可通过配方产出概率或数量体现。
- **满精力模拟**：按精力收益从高到低贪心分配，可重复制作；已扣交易税，不建模暴击额外产出与市场深度。

## 小程序端（微信 / 小红书）

同一套计算内核已移植为 **Taro 3.6.35 + React** 小程序，可同时编译到微信与小红书，源码在 [`miniapp/`](miniapp/README.md)。

```bash
cd miniapp
npm install
npm run build:weapp   # 微信小程序 → miniapp/dist/weapp
npm run build:xhs     # 小红书小程序 → miniapp/dist/xhs
```

- **为什么选 Taro**：小红书官方《框架开发》文档推荐 Taro 3.6.35，通过 `@tarojs/plugin-platform-xhs` 编译；不需要为两端各写一套原生代码。
- **兼容策略**：计算内核纯 JS 无 DOM；存储走 `Taro.getStorageSync/setStorageSync`；图表改用 **View + 百分比条形图**，不依赖 Canvas（小红书 Canvas 适配风险高）；不打开外链，来源链接提供复制。
- **数据同步**：`miniapp/scripts/sync-catalog.js` 从 `assets/data.js` 生成 `src/shared/catalog.json`；Web 数据更新后执行 `npm run sync:catalog`。
- **发布配置**：填写 `miniapp/project.config.json` 的微信 AppID 与 `project.xhs.json` 的小红书 AppID；两端 IDE 的导入方式、隐私/类目/审核清单见 [小程序 README](miniapp/README.md#发布前检查)。
- **体积**：微信主包约 1.08 MB、小红书约 1.1 MB，低于 2 MB 主包限制。

三端均包含：总览、生活技艺、价格库、精力收益分析、**突破升级（1→50 晋秩路线）**、配方详情/编辑、设置与备份；小程序端与其口径一致，差异是手机竖屏布局、View 图表、无 CSV/PNG 导出、仅暗色主题。

突破升级模块（Web 侧栏「突破升级」/ 小程序「分析 → 突破升级」）用当前服物价计算 8 项技艺从 1 到 50 级的最优冲级路线：30/35/40/45 级「晋秩」突破材料、每段等级的最优配方与产出价值、总精力/收益/制作次数，并支持「金币优先 / 精力优先 / 省心」三种维度。页面按1→30与30→50两阶段汇总：精力优先只比较最少精力，金币优先比较含突破材料的合计收益（税后产出价值−材料成本−突破材料，越高越好，赚钱绿色 +、亏损红色 −）。数据由 `scripts/build-breakthrough-data.mjs` 从 JX3BOX 技艺接口、拍卖行情与攻略生成，并同步产出 `miniapp/src/shared/breakthrough.json`、Web/小工具的 `breakthrough-data.js` ；计算模型统一使用 `miniapp/src/shared/breakthrough-model.js`，Web/小工具由脚本同步副本。

### JX3BOX 自动更新物价

离线小工具不能在运行时联网，自动更新放在构建/发布前：`scripts/update-jx3-prices.mjs` 会从 JX3BOX 拉取 17 个服务器的拍卖价，更新 Web / 小程序 / 小工具的 serverPrices 数据，并重打 minitool zip。

```bash
node scripts/update-jx3-prices.mjs --dry-run   # 预览
./scripts/update-prices.sh                     # 更新并重打包
```

支持 cron 定时执行；用法、样本阈值和注意事项见 [scripts/README.md](scripts/README.md)。

每次价格变化还会写入 `data/price-history/` 的按日 JSON（当天完整基线 + 后续增量），可回溯各服各时间点报价。查询和导出：

```bash
node scripts/price-history.mjs list
node scripts/price-history.mjs as-of 2026-11-20T12:00 --server 梦江南
node scripts/price-history.mjs export --server 梦江南 --from 2026-11-20 --effective --out /tmp/mj.csv
```

`--effective` 会用当日基准价补齐本服无报价物品，并标注“本服报价 / 基准价”，方便按历史物价重算产出物收益。结构与字段见 [data/price-history/README.md](data/price-history/README.md)。

## 已知边界

- 交易行手续费/税费、暴击额外产物、署名溢价、跨服交易限制未自动建模；可在「手续费」或材料价格中手动体现。
- 采集精力按当前赛季默认 40/次；紫苏 45、黄花菜/鱼腥草 50。产出数量与稀有掉率仍为示例，需要按游戏内实测校准。
- 配方库不是官方逐条数据；请以游戏内配方书与交易行行情为准。发现新版本改动时，直接编辑配方或在设置中导入新 JSON。
- 旧版本（90/100/130 级）配方与精力数值不兼容，已通过数据版本迁移整体切换，不会混入当前目录。

### 技艺突破核算口径

- 仅有 30/35/40/45 级四道晋秩任务，50 级为满级。
- 优先本服 `catalog.serverPrices` 的脚本 JX3BOX 报价，同名物品须匹配物品 key；缺报价时补用本服突破快照，不读取手动价、示例基准价或其他服务器报价。
- 精力优先只计算逐级最少总精力，不以价格或收益筛选配方。金币优先按已解锁且报价完整配方的金/精力数值范围等宽分三档，各档算术均值作为参考，选择该档完成升级收益最高的实际配方；三档统一用产量中点乘概率，不代表产量高低。空档不跨档补位。收益越高越好，赚钱显示绿色 +，亏损显示红色 −。
- 金币路线缺少任务材料报价时列出物品与数量，总费用留空；空档或缺少报价完整的配方时不跨档补位、不外推高等级配方/采集点。精力路线只要求等级、经验与精力有效，缺价不影响精力计算和排名。
- 经验表 1→2 至 49→50 共49行，含5个用户观测点、25个插值点和19个外推点；暂按八技艺共用门槛，技艺间差异未核实；未核实的任务脚本奖励不计入收益，任务接口未列普通奖励不能证明没有脚本奖励。1→30 阶段包含 30 级任务，30→50 包含 35/40/45 任务。
- 共用模型源文件：`miniapp/src/shared/breakthrough-model.js`；修改后执行 `node scripts/sync-breakthrough-model.mjs` 同步 Web/小工具副本，执行 `node scripts/test-breakthrough.cjs` 核对回归。Web 构建自动同步模型副本。

后续修改完成后自动提交推送并部署 Pages，协作规则见 [AGENTS.md](AGENTS.md)，发布流程见 [DEPLOY.md](DEPLOY.md)。GitHub Actions 自动维护 [CHANGELOG.md](CHANGELOG.md) 和站内更新说明。
